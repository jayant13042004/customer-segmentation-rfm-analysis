# Customer Segmentation & RFM Analysis

RFM-based customer segmentation on **1,067,371 transactions** from **5,881 customers**, with seasonality and product-category analysis in Power BI.

## What it does
- Processed the transaction data with Python and SQL
- Built **6 RFM-based customer segments** using rule-based RFM scoring
- Analyzed seasonality and product-category trends
- Presented the findings in a Power BI dashboard

## Key finding
Champions are about **22% of customers** but contribute about **68% of revenue**.
