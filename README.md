# Customer Segmentation & RFM Analysis

A customer analytics project using Recency, Frequency and Monetary (RFM) analysis to segment customers and study purchasing behaviour, revenue contribution and sales patterns.

## Project Overview

The project analyzes transaction data to understand customer purchasing behaviour and identify customer groups that may benefit from different engagement strategies.

The existing project documentation reports:

- **1,067,371 transactions**
- **5,881 customers**
- **6 RFM-based customer segments**
- Champions represented approximately **22% of customers** and contributed approximately **68% of revenue**.

These figures are retained from the original project documentation and have not been independently reproduced during this README update.

## Analysis Areas

- Customer purchasing behaviour
- Recency, Frequency and Monetary (RFM) analysis
- Customer segmentation
- Revenue contribution by customer segment
- Seasonal sales patterns
- Product-category analysis

## Technology Stack

Python, SQL, Pandas and Microsoft Power BI were used during the original project work.
